# 설정 캐시 통계 성능 (#182)

설정에 들어갈 때마다 pip·Maven·Conda의 디스크 캐시를 동기 순회하던 경로를 비동기 집계와 결과 재사용으로 바꿨습니다. 파일 저장·삭제·만료 정리가 결과를 무효화하고 동시 집계는 공유합니다. 수동 새로고침은 외부 프로세스의 파일 변경도 다시 집계합니다. [동작 계약](shared-cache.md#설정-화면의-통계-조회)

## 측정 조건

- 2026-09-28, macOS 26.3 / Apple M4 arm64, Electron 44.3.0 / 내장 Node 24.20.0.
- 기준 코드: `4b67cd4`. 비교 코드: #182 구현. 같은 lockfile에 맞는 기존 의존성을 양쪽에서 재사용했습니다.
- 임시 홈에 합성 pip JSON 12,000개, Maven POM·메타데이터 1,000개, Conda 2개 항목(파일 4개)을 생성했습니다. 실제 사용자 캐시는 읽거나 변경하지 않았습니다.
- 양쪽 모두 같은 기존 production renderer(0.2.30)를 로드했습니다. 메인 프로세스는 테스트용 TypeScript require hook으로 실행하고 preload만 임시 파일로 변환합니다. 앱 빌드·설치·패키징은 하지 않았습니다. Vite 준비 대기와 DevTools는 측정 harness에서 우회하며 앱 핸들러와 통계는 실제 코드를 실행합니다.
- 홈 → 설정 이동 후 3초간 메인 `process.cpuUsage()`, renderer CDP `TaskDuration`, IPC 호출 및 대상 캐시 경로의 파일 API 호출을 기록했습니다. 1ms 타이머 간격으로 이벤트 루프 지연도 관찰했습니다. 타이머·IPC 계측 자체의 CPU 비용과 네트워크·OS 캐시·JIT 변동을 포함합니다.

최초 집계의 최대 타이머 간격은 103.42ms에서 7.09ms로 줄었습니다. 수정 후 재진입에서는 1.88~2.15ms였습니다. 파일마다 비동기 작업으로 제어를 돌려주므로 1만 개 이상의 파일을 한 번에 동기 순회하지 않으며, 변경 없는 재진입에서는 파일 API 호출이 없습니다. IPC 자체는 진입마다 한 번 유지하여 현재 메모리 통계를 확인합니다.

**최초 집계의 전체 CPU 비용과 응답 완료 시간은 늘었습니다.** 이 변경은 최초 집계의 연속 이벤트 루프 점유를 줄이고 반복 집계를 없애는 개선입니다. 최초 집계 자체의 연산량 감소나 렌더러 최적화를 주장하지 않습니다. 같은 renderer를 사용했으므로 TaskDuration 차이를 UI 변경의 효과로 해석하지 않습니다. 폼의 지연 mount는 별도 하위 작업 프로파일 없이 적용하지 않았으며 저장·초기화·미저장 입력 보호를 유지했습니다. 이 수치는 배포 패키지의 CPU %나 일반적인 개선율이 아닙니다.

## 재현

동일 lockfile을 가진 이전 checkout과 기존 production renderer 경로를 준비합니다. 현재 checkout의 `node_modules`에 해당 lockfile의 Electron·Playwright·TypeScript가 있어야 합니다. 스크립트는 별도의 앱 빌드나 의존성 설치를 실행하지 않습니다.

```bash
node scripts/profile-settings-cache.mjs \
  /path/to/baseline-checkout \
  /path/to/existing/dist/renderer
```

스크립트는 최초 진입과 재진입 2회를 각 코드에 대해 실행합니다. 수정 코드에 동기 캐시 파일 호출이나 재진입 시 디스크 재집계가 발견되면 실패합니다. 표본 JSON과 합성 캐시는 출력한 임시 디렉터리의 `results.json` 및 `home/`에 남습니다. 재현이 끝난 뒤 해당 임시 디렉터리를 제거할 수 있습니다. 새 renderer를 비교하고 싶다면 별도의 동일 조건 프로파일로 구분해야 합니다.

기능 회귀는 [검증 명령](testing.md#설정-캐시-통계-182)의 단위·통합 테스트와 수정된 렌더러의 Playwright E2E로 확인합니다. 동시 요청, 집계 도중 변경, 쓰기·삭제·만료·304 갱신, 강제 새로고침, 실패·재시도, 늦은 응답 및 설정 저장·초기화·이탈 보호를 검사합니다.
